# Focusly ⏱

A beautiful, distraction-free focus timer with everything you need to stay in flow.

## Features
- ⏱ Standard & Pomodoro timer modes
- 🔵 Progress ring with pulse animation
- 🎵 Spotify focus playlists + local music player
- 🌧 Ambient sound mixer (Rain, White noise, Brown noise, Cafe)
- 📊 Session stats, streaks & GitHub-style heatmap
- 🖼 Custom wallpaper with auto-contrast detection
- ⚡ Quick session presets
- 🌙 Dark / Light mode

## Usage
Just open `index.html` in any browser — no install, no dependencies, no backend.
